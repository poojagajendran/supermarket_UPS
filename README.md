# Supermarket Billing System

## About the Project
This is a simple Supermarket Billing System developed using Java. It allows users to select products, enter quantities, and calculate the total bill.

## Features
- Display product categories.
- Select fruits and snacks.
- Enter product quantities.
- Calculate the total bill.
- Display the final bill.
- Exit the application.

## Concepts Used
- Java
- Switch Case
- Nested Switch Case
- Do-While Loop
- If Statement
- Scanner Class

## Products Available

### Fruits
- Apple – ₹100
- Banana – ₹50

### Snacks
- Biscuit – ₹20
- Chips – ₹30

## How to Run
1. Install Java JDK.
2. Save the code as `supermarketproject.java`.
3. Open the terminal in the project folder.
4. Compile the program:

   ```bas
   javac supermarketproject.java
   ```

5. Run the program:

   ```bash
   java supermarketproject
   ```

## Conclusion
This project demonstrates the basic concepts of Java programming by implementing a simple supermarket billing system.
